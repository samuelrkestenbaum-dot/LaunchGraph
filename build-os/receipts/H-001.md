## 5. Process incident — the session's THIRD Trap-9 instance, caught in-flight

The first version of the two dynamic-import regression tests **passed pre-fix,
vacuously**: helper files were placed under `app/api/stripe/webhook/`, and
`isWebhookHandler` matches **ANY** code file under a webhook-ish `/api/` path,
so the helpers were located as handlers (all-handlers semantics) and
`RECONCILING_HELPER`'s own quoted `import { db } from './db'` armed the guard
through them — the tests proved the wrong shape. **Caught by running the
negative control BEFORE the fix** — the discipline working as designed. Helpers
moved to `lib/`; all three arming tests then red pre-fix, green post-fix; the
reviewer independently re-verified via the pre-fix overlay.

**Standing lesson, carried to memory:** on this codebase, any test file placing
a repo file under a webhook-ish path has put a **HANDLER** there, whether it
meant to or not.
