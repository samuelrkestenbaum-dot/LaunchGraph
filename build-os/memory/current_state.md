## Project

- **What this repo is:** **SugarBee.ai** — a production-readiness auditor for AI-built SaaS. The shipping wedge (Phase 1) is a narrow, structurally read-only static auditor for TypeScript/Next.js repos: 15 evidence-backed checks producing a Ready / Ready with warnings / Not ready decision. Never executes the scanned repo, reads no provider credentials, instantiates no provider SDKs; the only permitted network egress is SugarBee's own model API. Founding scope: `PRODUCT_SCOPE.md`.
